03IDEAM Station Data Downloader

Individual project, designed and developed by me. Public release is pending authorization from IDEAM. It is not an official IDEAM product.

Problem. IDEAM, Colombia's national institute for hydrology and meteorology, publishes its station records through the DHIME portal, which returns data for one station and one query at a time. A watershed study may require dozens or hundreds of stations, each downloaded and merged by hand.

Solution. A web application in which the user defines a study area on a map. The application identifies every station within it, estimates the data coverage of each station for the requested period, and returns a single organized package with merged spreadsheets, a summary table and the source citation.

04Methodology

  1. Study area. Drawn on the map or uploaded as a vector file. The coordinate reference system is verified and invalid geometries are repaired.
  2. Buffer. Computed in a metric projection (MAGNA-SIRGAS, EPSG:3116) and returned to WGS84, so distances are measured in true kilometers.
  3. Spatial selection. Point-in-polygon spatial join between the station catalog and the study area plus buffer. Selection by department, municipality or station code is also available.
  4. Coverage screening. Each station is classified by the share of the requested period covered by its records: high (≥ 70%), medium (≥ 50%), low (≥ 25%) or critical.
  5. Quality control. The catalog altitude of each station is compared with a terrain model, and inconsistent stations are flagged for review.
  6. Data extraction. Requests to the portal are automated, split into yearly blocks and limited to four concurrent downloads to avoid overloading the public service.
  7. Deliverable. One merged Excel file per station, a summary CSV, folders by coverage class and a citation file in the format required by IDEAM.

07Proposed approach for an initial site screen

  1. Map the interstate corridors (I-10, I-17, I-40, I-8, I-19), their interchanges and existing truck stops, and identify coverage gaps.
  2. Rank interchanges by truck traffic, distance to the nearest competitor and population within a defined radius.
  3. Review parcels near the highest-ranked interchanges: acreage, ownership, zoning, access and land status (private, State Trust, federal or tribal).
  4. Flag constraints such as flood zones and environmental records, with links to each source.
  5. Deliver a site tracker and a one-page summary per site with key findings and a recommendation.

Station data belongs to IDEAM and is cited in every download. Basemaps belong to their respective providers.
